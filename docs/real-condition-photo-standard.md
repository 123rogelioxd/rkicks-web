# RKicks Real Condition Photo Standard

Every public RKicks listing should document the exact pair being sold. The public site already supports multiple product photos through the live product `photos` field; the editor process should require the checklist below before a pair is published.

## Required Photos

1. Lateral side
2. Medial side
3. Heel
4. Toe box
5. Sole
6. Size tag
7. Box
8. Defects, if any

## Publishing Rule

A product is ready for sale only when the buyer can verify:

- the exact pair,
- the declared size,
- the box status,
- visible condition,
- and every disclosed defect.

## Defect Photo Rule

If a defect is mentioned in the condition report, include both:

- a context photo showing where it is on the pair,
- and a close-up photo showing severity.

## Buyer Confidence Goal

The listing should answer this before WhatsApp:

> "Is this the real pair, in my size, in the condition described?"
